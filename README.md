# SQL Practice & Advanced Database Concepts 

A repository containing basic-to-advanced SQL queries, database modeling, and practice scripts using MySQL.

---

##  Topics Covered

* **SQL Basics:** SELECT, Data Types, Operators, LIKE, and DCL Commands
* **Functions & Aggregation:** String Functions, Date Functions, GROUP BY, and ORDER BY
* **Joins & Subqueries:** Inner/Outer Joins, Subqueries, and Complex Multi-Table Queries
* **Advanced SQL:** CTEs, Window Functions, Cursors, and Data Modeling
* **Practice Sets:** Problem sets and Sakila Sample Database queries

---

##  Tools
* **Database:** MySQL / MySQL Workbench
* **Language:** SQL
